# Planes archivados

Planes **terminados o descartados**. Sirven como contexto histórico:
explican por qué algo se hizo así.

**No son fuente de verdad.** Si un plan archivado contradice a
[`map.md`](../../map.md) o al código, gana el código.

Al archivar, agrega arriba del archivo una línea con cómo cerró:
`Cerrado 2026-MM-DD — implementado / descartado porque …`.
