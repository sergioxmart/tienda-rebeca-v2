# Planes activos

Planes de trabajo **en curso**. Antes de empezar una feature, mira si ya
hay un plan escrito acá.

Un archivo por plan: `NN-nombre-corto.md`. Sugerencia de contenido:
objetivo, alcance (qué sí y qué no), pasos, archivos que se tocan y
criterio de "listo".

Cuando un plan se termina o se descarta, muévelo a
[`../archivo/`](../archivo/) con una nota de cómo cerró.

> "Estado del proyecto" en [`../../map.md`](../../map.md).
